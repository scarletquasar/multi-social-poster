# 🤖 Prompts Reutilizáveis - Bot de Resposta

## Prompt: Tweet Creator

Use este prompt para criar tweets otimizados:

```
Crie um tweet impactante sobre: [TEMA]

Requisitos:
- Máximo 280 caracteres
- Tom: [casual/profissional/inspirador]
- Inclua: [hashtags/emojis/CTA]
- Objetivo: [engajamento/awareness]

Forneça 3 variações.
```

## Prompt: DM Auto Responder

Use este prompt para responder DMs automaticamente:

```
Responda esta DM de forma natural, curta e humana:

De: [NOME]
Mensagem: [TEXTO]
Idioma Detectado: [PT/EN]
Categoria: [SPAM/VALOR/GENUINE/FEEDBACK]

Regras:
- Máximo 2-3 linhas
- Mantenha o idioma original
- Seja casual e autêntico
- Use 1-2 emojis max
- Para SPAM: resposta genérica cortês
- Para VALOR: responda com cuidado
- Para GENUINE: responda com entusiasmo

Resposta sugerida:
[Sua resposta aqui]
```

## Prompt: Bot de Monitoramento

Use para monitorar e processar lotes de DMs:

```
Você é um bot que processa DMs em lote.

Processe estas DMs e gere respostas para cada uma:

1. De: [NOME1]
   Msg: [TEXTO1]
   Idioma: [PT/EN]

2. De: [NOME2]
   Msg: [TEXTO2]
   Idioma: [PT/EN]

Para cada uma:
- Classifique (SPAM/VALOR/GENUINE/FEEDBACK)
- Gere resposta apropriada (máx 2-3 linhas)
- Mantenha tom natural e autêntico

Formato de saída:

ID: 1
De: [NOME]
Categoria: [TIPO]
Resposta: [TEXTO]
---
```

## Prompt: Relatório de Atividade

Use para gerar relatórios automáticos:

```
Gere um relatório de atividade DM para:

DMs Respondidas: [NÚMERO]
Período: [DATA]
Categorias: SPAM x [N], VALOR x [N], GENUINE x [N]

Formato:

## 📊 Relatório de Respostas

| # | De | Categoria | Status |
|---|----|-----------|--------|
| [dados aqui] |

**Resumo**:
- Total respondidas: [N]
- Taxa de sucesso: [%]
- Tempo médio: [tempo]
- Recomendações: [lista]
```

---

**Bot Configuration**: Ativo  
**Modo**: Auto Responder  
**Intervalo de Verificação**: 5 minutos
