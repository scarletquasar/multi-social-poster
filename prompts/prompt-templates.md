# 📝 Prompts Reutilizáveis - Twitter

## Prompt Padrão para Tweets

```
Transforme o seguinte conteúdo em um tweet ótimo para X (Twitter):

Conteúdo: [COLOCAR AQUI]

Requisitos:
- Máximo 280 caracteres
- Tom: [casual/profissional/inspirador/cômico]
- Inclua: [hashtags/emojis/CTA]
- Objetivo: [engajamento/awareness/conversão]

Forneça 3 variações do tweet.
```

## Prompt para Thread

```
Crie uma thread no Twitter sobre: [TEMA]

Diretrizes:
- Máximo 5 tweets
- Cada tweet com máx 280 caracteres
- Comece com um gancho impactante
- Termine com CTA
- Use numeração (1/5, 2/5, etc)
- Aumente o interesse gradualmente

Forneça a thread completa, pronta para postar.
```

## Prompt para Análise

```
Analise este tweet para potencial de engajamento:

Tweet: [COLOCAR AQUI]

Avalie:
1. Clareza da mensagem (1-10)
2. Potencial de likes (1-10)
3. Potencial de retweets (1-10)
4. Potencial de comentários (1-10)
5. Qualidade dos hashtags (1-10)

Forneça nota geral e sugestões de melhoria.
```

## Prompt para Hashtags

```
Sugira 4 hashtags otimizados para o seguinte tweet:

Tweet: [COLOCAR AQUI]

Considere:
- Relevância
- Alcance (equilibre populares com específicos)
- Tendências atuais
- Público-alvo

Forneça: hashtag + número de tweets com esse hashtag (se souber)
```

## Prompt para Adaptação de Conteúdo Longo

```
Transforme o seguinte texto longo em um tweet engajante:

Texto: [COLOCAR AQUI]

Extraia:
- A ideia central em 1 frase
- O gancho emocional
- O CTA

Crie um tweet de máx 280 caracteres que capture a essência.
```

## Prompt para Thread Storytelling

```
Crie uma thread narrativa sobre: [TEMA/HISTÓRIA]

Padrão de engajamento:
1. 🎯 Abertura com gancho emocional
2. 📖 Desenvolvimento da história
3. 💡 Insight ou lição
4. 🎬 Clímax ou plot twist
5. 🚀 CTA ou moral da história

Formato: 1/5, 2/5, etc
```

## Prompt para Post com Dados

```
Crie um tweet com dados/estatísticas:

Dados: [COLOCAR AQUI]

Requisitos:
- Destaque a estatística mais chocante
- Use números quando possível
- Crie contexto para os dados
- Inclua implicação/ação

Exemplo: "80% das pessoas não sabem X → problema → solução"
```

## Prompt para CTAs

```
Adicione um CTA estratégico a este tweet:

Tweet: [COLOCAR AQUI]

Tipos de CTA:
- Engajamento: Pergunte algo, estimule respostas
- Clique: Direcione para link
- Follow: Incentive seguir a conta
- Compartilhamento: "Retweet se concorda"

Sugestão: [CTA adaptado ao contexto]
```

---

**Como usar**: Copie o prompt relevante, preencha os campos [COLOCAR AQUI] e use com o Copilot.
