# Multi-Social Poster 🚀

Uma ferramenta potenciada por Copilot para postar conteúdo em múltiplas redes sociais simultaneamente, com adaptação automática do conteúdo para cada plataforma.

## 🎯 Objetivo

Transformar o GitHub Copilot em uma ferramenta inteligente que:
- Posta em várias redes sociais ao mesmo tempo
- Adapta o conteúdo automaticamente para cada plataforma
- Respeita limitações de caracteres, formatos e guidelines de cada rede
- Otimiza hashtags, emojis e tom de voz por plataforma

## 🚀 Como Usar

1. Prepare seu conteúdo inicial
2. Ative o Copilot
3. Use o prompt: `/post-multi <seu conteúdo>`
4. O Copilot adaptará automaticamente para cada plataforma
5. Revise e publique

## 💡 Funcionalidades

- ✨ Adaptação inteligente de conteúdo por plataforma
- 🎯 Otimização de hashtags
- 📊 Análise de limites de caracteres
- 🎨 Sugestões de emojis contextuais
- 🔄 Variação de tom de voz
- 📋 Histórico de postagens
